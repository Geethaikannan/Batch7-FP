import numpy as np
from sklearn.preprocessing import LabelEncoder, StandardScaler

def preprocess_data(df):
    """
    Preprocess the UNSW-NB15 dataset.
    
    Parameters:
    -----------
    df : pandas.DataFrame
        The input DataFrame to preprocess
    
    Returns:
    --------
    X : numpy.ndarray
        Preprocessed feature matrix
    y : pandas.Series
        Target labels (0 for normal, 1 for attack)
    """
    df = df.copy()

    # Remove ID column if exists
    if 'id' in df.columns:
        df.drop(columns=['id'], inplace=True)

    # Separate label
    y = df['label']
    X = df.drop(columns=['label'])

    # Encode categorical columns
    for col in X.select_dtypes(include=['object']).columns:
        le = LabelEncoder()
        X[col] = le.fit_transform(X[col])

    # Scale features
    scaler = StandardScaler()
    X = scaler.fit_transform(X)

    return X, y
---

Explanation:
- The preprocess_data function performs the following steps:
  1. Creates a copy of the DataFrame to avoid modifying the original
  2. Removes the 'id' column if it exists (not useful for training)
  3. Separates the 'label' column (target variable) from features
  4. Encodes categorical columns using LabelEncoder (converts string categories to numbers)
  5. Scales numerical features using StandardScaler (standardizes features to have mean=0 and std=1)
  6. Returns preprocessed features (X) and labels (y)

Key Concepts:
- LabelEncoder: Converts categorical string values to numerical values (e.g., 'tcp' -> 0, 'udp' -> 1)
- StandardScaler: Standardizes features by removing the mean and scaling to unit variance

Usage:
    from preprocessing import preprocess_data
    X_train, y_train = preprocess_data(train_df)
    X_test, y_test = preprocess_data(test_df)

Code:
---
import numpy as np

class QABNN:
    """
    Quantum-inspired Attention-based Binary Neural Network (QABNN)
    
    This model uses binary prototypes for classification, inspired by quantum
    computing concepts where states are binary (0 or 1).
    """
    
    def __init__(self):
        """Initialize the QABNN model."""
        self.normal_proto = None
        self.attack_proto = None

    def binarize(self, X):
        """
        Convert continuous features to binary values.
        
        Parameters:
        -----------
        X : numpy.ndarray
            Input feature matrix
        
        Returns:
        --------
        X_bin : numpy.ndarray
            Binary feature matrix (0 or 1)
        """
        return (X > 0).astype(np.uint8)

    def fit(self, X, y):
        """
        Train the QABNN model by computing prototypes.
        
        Parameters:
        -----------
        X : numpy.ndarray
            Training feature matrix
        y : numpy.ndarray or pandas.Series
            Training labels (0 for normal, 1 for attack)
        """
        X_bin = self.binarize(X)

        # Separate normal and attack samples
        normal_samples = X_bin[y == 0]
        attack_samples = X_bin[y == 1]

        # Compute prototypes (mean of binary samples)
        self.normal_proto = np.mean(normal_samples, axis=0)
        self.attack_proto = np.mean(attack_samples, axis=0)

    def predict(self, X):
        """
        Make predictions using prototype distance.
        
        Parameters:
        -----------
        X : numpy.ndarray
            Feature matrix to predict
        
        Returns:
        --------
        predictions : numpy.ndarray
            Binary predictions (0 for normal, 1 for attack)
        """
        X_bin = self.binarize(X)

        # Calculate Hamming distance to normal prototype
        normal_dist = np.sum(
            np.bitwise_xor(X_bin, self.normal_proto > 0.5),
            axis=1
        )

        # Calculate Hamming distance to attack prototype
        attack_dist = np.sum(
            np.bitwise_xor(X_bin, self.attack_proto > 0.5),
            axis=1
        )

        # Predict attack if closer to attack prototype
        return (attack_dist < normal_dist).astype(int)
---

Explanation:
- The QABNN class implements a quantum-inspired binary neural network
- Key concepts:
  1. Binarization: Converts continuous features to binary (0 or 1) using threshold 0
  2. Prototypes: Computes mean binary vectors for each class (normal and attack)
  3. Prediction: Uses Hamming distance (bitwise XOR + sum) to determine the nearest prototype
  4. Decision: If the distance to attack prototype is less than distance to normal prototype, predict attack

Quantum Inspiration:
- In quantum computing, qubits can be in superposition but measure to binary states
- The prototype approach is similar to quantum state representation
- Hamming distance mimics quantum measurement

Usage:

    qabnn = QABNN()
    qabnn.fit(X_train, y_train)
    predictions = qabnn.predict(X_test)

from data_loader import load_data
from preprocessing import preprocess_data
from qabnn import QABNN
from sklearn.metrics import classification_report, confusion_matrix
from sklearn.ensemble import RandomForestClassifier

TRAIN_PATH = "../data/UNSW_NB15_training-set.csv"
TEST_PATH = "../data/UNSW_NB15_testing-set.csv"


def main():
    """
    Main training and evaluation pipeline.
    
    This function:
    1. Loads the training and testing data
    2. Preprocesses the data
    3. Trains and evaluates QABNN model
    4. Trains and evaluates Random Forest baseline
    5. Compares the results
    """
    # Step 1: Load data
    train_df, test_df = load_data(TRAIN_PATH, TEST_PATH)

    # Step 2: Preprocess data
    X_train, y_train = preprocess_data(train_df)
    X_test, y_test = preprocess_data(test_df)

    # Step 3: Train and evaluate QABNN
    qabnn = QABNN()
    qabnn.fit(X_train, y_train)
    y_pred_qabnn = qabnn.predict(X_test)

    print("QABNN Results")
    print(confusion_matrix(y_test, y_pred_qabnn))
    print(classification_report(y_test, y_pred_qabnn))

    # Step 4: Train and evaluate Random Forest baseline
    rf = RandomForestClassifier(n_estimators=100)
    rf.fit(X_train, y_train)
    y_pred_rf = rf.predict(X_test)

    print("Random Forest Results")
    print(confusion_matrix(y_test, y_pred_rf))
    print(classification_report(y_test, y_pred_rf))

if __name__ == "__main__":
    main()

================================================================================
COMPLETE WORKFLOW
================================================================================

The complete workflow of the NIDS-QABNN project is as follows:

1. DATA LOADING PHASE
   - Read training data from CSV: data/UNSW_NB15_training-set.csv
   - Read testing data from CSV: data/UNSW_NB15_testing-set.csv
   - Store as pandas DataFrames

2. DATA PREPROCESSING PHASE
   - Remove unnecessary columns (e.g., 'id')
   - Separate features (X) from labels (y)
   - Encode categorical features using LabelEncoder
   - Scale numerical features using StandardScaler

3. MODEL TRAINING PHASE
   QABNN Model:
   - Binarize all features (convert to 0 or 1)
   - Compute binary prototype for normal traffic (mean of normal samples)
   - Compute binary prototype for attack traffic (mean of attack samples)
   
   Random Forest Model (Baseline):
   - Train 100 decision trees
   - Use bootstrap sampling
   - Combine predictions through voting

4. PREDICTION PHASE
   QABNN Model:
   - Binarize test features
   - Calculate Hamming distance to each prototype
   - Assign class based on nearest prototype
   
   Random Forest Model:
   - Pass features through all decision trees
   - Aggregate predictions (majority vote)

5. EVALUATION PHASE
   - Compute confusion matrix
   - Calculate precision, recall, F1-score
   - Compare QABNN vs Random Forest performance

================================================================================
KEY CONCEPTS FOR AI AGENT TRAINING
================================================================================

1. NETWORK INTRUSION DETECTION
   - Binary classification: Normal (0) vs Attack (1)
   - Features: Network traffic attributes (protocol, bytes, packets, etc.)
   - Goal: Minimize false negatives (missed attacks) while maintaining reasonable false positives

2. QUANTUM-INSPIRED COMPUTING
   - QABNN uses binary representation similar to quantum bits (qubits)
   - Prototype-based classification is inspired by quantum state vectors
   - Hamming distance mimics quantum measurement

3. MACHINE LEARNING PIPELINE
   - Data loading → Preprocessing → Training → Evaluation
   - Importance of data preprocessing (encoding, scaling)
   - Model comparison with baselines

4. EVALUATION METRICS
   - Accuracy: Overall correctness
   - Precision: Of predicted attacks, how many are real attacks
   - Recall: Of real attacks, how many were detected
   - F1-score: Harmonic mean of precision and recall
   - Confusion Matrix: Shows all prediction categories
