The IDS-Project is a Network Intrusion Detection System (NIDS) implementation utilizing a Quantum Approximate Binary Neural Network (QABNN) approach. The project is structured within the NIDS-QABNN directory, which includes essential components for data handling and analysis. It features a data directory containing the UNSW NB15 dataset files (training and testing sets in CSV format), a notebooks directory with a Jupyter notebook for initial data checking, and a source code directory (src) housing Python modules for data loading and preprocessing. The data_loader.py module provides functionality to load the training and testing datasets using Pandas, while preprocessing.py likely handles data preparation tasks. The project relies on standard Python data science libraries such as NumPy, Pandas, Scikit-learn, Matplotlib, and Seaborn, as specified in the requirements.txt file, to support machine learning and visualization for intrusion detection purposes.
